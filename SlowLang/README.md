# SlowLang

SlowLang (also called TortoiseLang) is a sarcastic, Python-based esoteric
programming language and IDE that enforces a ~30 WPM typing speed limit.

- Type faster than the cap: an angry ASCII turtle appears, you get a
  2-second rage lockout, and error messages arrive as sarcastic haikus.
- A mandatory `please()` builtin is demanded at random 3-7 line intervals;
  rude code is refused.
- Lazy mode randomly refuses ~10% of perfectly valid runs.
- Turing complete: `.slow` files execute as Python under the hood.

Won first place at TinkerHub's Useless Projects 2.0 hackathon (Aug 2025),
built by CS students at College of Engineering Chengannur, Kerala, India.
